# Cost of one run - measured 2026-11-08 19:07

This system calls no paid API and uses no tokens. The cost of a run is compute on the local machine: wall time, CPU time and memory.

## How it was measured

- `python tools/measure_cost.py --launches 1 --runs 30` (Python 3.11.9, win32, model `gpt2`, `DETECTOR_MAX_TOKENS` 400).
- Each launch starts a fresh server, so the first request is a true cold start. It is timed alone. 30 warm runs of one fixed 103-word text follow, one at a time, each under its own `creator_id`.
- Client time is `perf_counter` around the HTTP call. Wall duration, CPU time and per-signal time come from the service's own run record in `logs/runs.jsonl` (`duration_ms`, `cpu_ms`, `model_ms`, `style_ms`), matched by `creator_id`.
- `cpu_ms` is process-wide CPU time over the request (`time.process_time`), valid because requests were sent one at a time. It can exceed wall time because torch uses several cores.
- Memory is the working set of the listening process from `tasklist`, before and after the cold run.
